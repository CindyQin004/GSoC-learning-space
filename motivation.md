# Motivation
This is my first time working with agent-based modeling, and I found myself genuinely enjoying the learning process. Running the Boltzmann Wealth Model and watching abstract concepts turn into visualized results was exciting. I want to keep exploring this field, and contributing to mesa-examples feels like a natural way to do that: learning deeper while helping improve the resources that the next newcomer will use.


## Who I am
I'm Yuning Qin (Cindy), a sophomore studying Computer Science and Engineering at Bucknell University with a minor in Mathematics. I enjoy building things from scratch and figuring out how systems work. In my Software Engineering course, I built a Mastermind game engine in Java and added a third solving algorithm to compare efficiency. In my VR research, I used the PRISMA framework to systematically review 21 papers. I like digging deep into problems and organizing information into clear structures.

## Why Mesa
To be honest, I only learned about this project at the end of March, so time was tight. But when I ran the Boltzmann Wealth Model and watched wealth gradually concentrate among a few agents, I found it fascinating. It lets you "see" phenomena that are usually only understood abstractly. Then I tried running other examples in mesa-examples and hit quite a few bumps, some wouldn't run at all. But it was precisely because of these bumps that I truly understood what this project is trying to solve.
